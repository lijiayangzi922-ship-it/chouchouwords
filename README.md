# ChouChouWORDS

一个温柔可爱的英语学习小窝。每天 25 分钟，练习听力、口语、词块与语法。

## 功能

- 首周 7 节互动课程：合成英语朗读、双语原文、填空核对、自由写作和打卡导出。
- 单词书：四级、六级、中考、高考、雅思分类词汇，以及 120 条原创场景表达。
- 搜索、收藏、掌握标记、拼写练习和单词书记录导入/导出。
- 纸张质感与手绘小图标，适配手机和电脑。

## 使用说明

网站入口是 index.html，不需要安装依赖或运行构建。GitHub Pages 可从 main 分支根目录发布。

学习记录保存在当前浏览器中，不会自动同步到其他设备或聊天。首次使用公开网址时，原本本地文件中的记录不会自动迁移。英语朗读使用浏览器及设备提供的语音；实际发音反馈需要可听取的录音。

## 词库来源

考试分类词库基于 [ECDICT](https://github.com/skywind3000/ECDICT)，版本 ab22ad36302cafc6349a050e2b60894855208055，使用其分类标签；不声称与最新官方考试大纲逐词一致。四级 3,849 条、六级（含四级）5,805 条、中考 1,603 条、高考 3,677 条、雅思 5,040 条。分类之间存在重叠。
